# Vonex SEO Growth Engine

Purpose: central operating system for SEO research and execution across:

- https://www.vonex.ca — local/service authority
- https://shop.vonex.ca — Canadian ecommerce authority

## Operating model

1. Pull first-party performance from Google Search Console.
2. Research competitor rankings, keywords, backlinks, and content gaps.
3. Prioritize opportunities where Vonex can realistically gain visibility.
4. Map every keyword to one canonical Vonex URL.
5. Improve existing pages before creating unnecessary new pages.
6. Build useful supporting content and legitimate citations/mentions.
7. Track indexing, rankings, clicks, CTR, conversions, and referring domains.
8. Review weekly and adjust priorities.

## Guardrails

We do not mass-generate backlinks or thin Google properties. Google considers automated link creation intended to manipulate rankings link spam. Supporting assets must have a real user purpose and add useful information.
